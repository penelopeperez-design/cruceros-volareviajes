# Landing de campaña — Cruceros 2027 · Volare Viajes

Sitio estático de la campaña de venta anticipada de cruceros 2027.

- Objetivo: llevar el tráfico de redes sociales al buscador de cruceros de volareviajes.com.
- Publicación: GitHub Pages, con el dominio personalizado `cruceros.volareviajes.com`.
- Contenido generado a partir del itinerario y las imágenes propias de la agencia.

## Estructura

- `index.html`: página completa (hero, cruceros destacados, venta anticipada, destinos, cómo funciona, preguntas frecuentes, contacto).
- `assets/`: CSS y JS compilados.
- `img/`: imágenes optimizadas.
- `CNAME`: dominio personalizado de GitHub Pages.
